## 🔧 Technical Specifications

The **2025 Honda CRF300L Rally** has the following specs:

- 🏍️ **Engine Displacement:** 300cc  
- ⚡ **Horsepower:** 27 HP  
- 🔥 **Torque:** 25 Nm  
- ⛽ **Fuel Type & Efficiency:** Petrol, 70 MPG  
- 🔄 **Transmission Type:** Manual  
- ⚖ **Weight:** 142 kg  
- 🚀 **Top Speed:** 145 km/h  
- 🛑 **Braking System:** Disc Brakes (ABS)  
- 🏗️ **Suspension System:** Telescopic Forks (Front), Monoshock (Rear)  
- 🛞 **Tire Size & Type:** Front: 80/100-21, Rear: 120/80-18 (Off-Road)
